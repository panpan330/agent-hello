# M11 第 2 节：PDF 类型、文本提取、OCR 与版面识别

## 本节定位

上一节回答“为什么企业需要文档 RAG”。本节进入资料加工的第一道关口：一份 PDF 到底是什么？系统怎样判断应直接提取文字、做 OCR，还是必须恢复页面布局？

这个判断错误，会让后面的清洗、分块、embedding 和回答建立在已损坏的输入上。它不是工具选择细节，而是数据质量的起点。

## 本节学习目标

1. 理解 PDF 的页面模型与文字层。
2. 区分原生文本 PDF、扫描 PDF、混合 PDF、复杂版面 PDF。
3. 区分文本提取、OCR、版面识别的职责边界。
4. 建立“先诊断、后处理、再验收”的文档处理流程。
5. 理解 OCR 置信度、图像质量、语言和布局为何影响业务正确性。

## 一句话先讲透

**文本提取回答“PDF 内部记录了什么字符”，OCR 回答“图片上写了什么字”，版面识别回答“这些内容应该怎样组织和阅读”；三者解决的是不同层次的问题。**

## 基础知识铺垫

### 1. PDF 不等于可编辑文档

Word 通常保存段落、标题、列表和表格单元格等逻辑结构。PDF 更接近“在一张页面的某个坐标画出字符、图片和线条”的描述。

人类看到：

```text
标题
第一段正文
第二段正文
脚注
```

程序可能看到：

```text
字符 A 在 x1,y1；字符 B 在 x2,y2；一条横线；一张图片。
```

因此 PDF 在阅读器中显示正常，并不代表它内部保存了正确的段落和阅读顺序。

### 2. 什么是文字层

文字层是 PDF 中可供搜索、复制和辅助阅读的字符信息。你能选中一句话并复制到记事本，通常表示该页有文字层。

但有文字层也可能：

```text
复制顺序混乱。
使用异常字体映射，提取后变乱码。
双栏左右内容交替出现。
隐藏 OCR 文字层与页面图片重复。
表格字符存在，但字段关系丢失。
```

所以“能复制”只说明可以尝试文本提取，不说明结果可直接进入知识库。

### 3. 三种处理能力

| 能力 | 输入前提 | 主要任务 | 不能保证什么 |
| --- | --- | --- | --- |
| 文本提取 | 有可用文字层 | 读取内部字符与部分坐标信息 | 正确阅读顺序、表格关系 |
| OCR | 页面或区域是图片 | 从图像识别文字 | 原文绝对正确、版面语义完整 |
| 版面识别 | 页面有空间布局 | 区分标题、段落、表格、图注、页眉脚并恢复顺序 | 文字识别本身一定准确 |

真实系统常组合使用。比如正文直接提取，扫描附件 OCR，双栏和表格再加版面分析。

## 本节主题系统讲解

### 1. 四类常见 PDF

#### 原生文本 PDF

由 Word、网页或业务系统直接导出，通常有文字层。优点是字符提取快、成本低、准确率通常高；风险是双栏、页眉页脚、字体映射和复杂表格。

#### 扫描 PDF

纸质文件、传真或拍照件形成的页面图片。典型表现是文字无法选择，放大后有像素颗粒、阴影和倾斜。它必须依赖 OCR，且可能受印章、手写批注、压缩和分辨率影响。

#### 混合 PDF

正文可复制，但附件、截图、表格或签章页是图片。不能按整份文件“一刀切”，应细到页面或区域判断处理路径。

#### 复杂版面 PDF

可能叠加双栏、跨页表格、图文混排、脚注、旋转页、多语言、公式等难题。它的核心不是能否读到字，而是能否保住内容之间的关系。

### 2. 文件诊断比处理更早

拿到文件后先做诊断：

```text
文件能否打开、是否加密、是否损坏？
总页数和每页尺寸、方向是否异常？
每页是否有可用文字层？
提取文本是否为空、乱码或高度重复？
是否有表格、双栏、图片文字、手写批注和旋转页？
主要语言是什么，是否中英与编号混排？
需要保留哪些证据：页码、版本、图表、签章、表单？
```

诊断的价值是按复杂度升级处理：普通页不做昂贵 OCR，疑难页不被误当普通文本，低质量页明确进入复核而不是静默入库。

### 3. 一条处理决策链

```text
能打开吗？
  否 -> 标记失败，要求重新上传或人工处理。
  是 -> 有足够文字层吗？
        否 -> OCR 路径。
        是 -> 文本质量和顺序合格吗？
              否 -> OCR、版面分析或人工复核。
              是 -> 是否有复杂表格、双栏、图文混排？
                    是 -> 加结构与版面恢复。
                    否 -> 进入清洗与分块。
```

这里“合格”不能只指接口不报错，而是指能支持后续业务问题。例如政策页的标题、正文、例外、页码没有明显丢失或错序。

### 4. OCR 的工作过程与误差来源

OCR 通常经过：

```text
页面渲染为图像
-> 纠偏、去噪、裁边、增强对比
-> 检测文字区域
-> 识别字符和词
-> 推断阅读顺序
-> 输出文字、位置与置信度
```

常见误差：

| 来源 | 后果 |
| --- | --- |
| 分辨率低 | 小字、数字、标点和表格线容易错 |
| 倾斜与阴影 | 行检测、阅读顺序错乱 |
| 印章和手写 | 遮挡关键字或被误识为正文 |
| 中文相似字 | “已/己”“未/末”等混淆 |
| 数字字母混淆 | `0/O`、`1/I/l`，影响编号和日期 |
| 多语言混排 | 语言模型不匹配造成漏识或断词 |

OCR 置信度只反映模型对识别结果的相对把握，不等于“该业务结论有 99% 真实”。金额、日期、合同号、税率等高风险字段仍需要格式校验、来源页和必要的人工核验。

### 5. 为什么版面识别不可省略

假设左栏是可退款条件，右栏是不可退款条件。若提取顺序左右交替，所有句子也许都正确，但拼成后会变成自相矛盾的规则。

版面识别需要尽可能识别：

```text
标题、章节标题、正文、列表、表格、图片、图注、页眉、页脚、脚注。
```

并恢复区域顺序与关联关系。它的价值不是让输出“更美观”，而是防止真实文字被错误组合成错误事实。

### 6. 处理质量如何验收

至少做三层检查：

```text
自动检查：空页、乱码、重复、页数覆盖、低置信度、异常短长文本。
结构检查：标题、段落、表格、图注、页码、脚注是否保留关系。
业务抽样：用真实问题核验关键规则、例外、金额、日期和表格字段。
```

重要原则是：无法可靠解析的内容应标记为待复核、限制自动回答或保留原页供人查看，不应因为“系统需要返回内容”就生成确定结论。

## 常见误区

### 误区 1：所有 PDF 都做 OCR 最保险

不对。原生文本直接提取通常更快、更便宜、字符更准。强制 OCR 反而会引入新识别错误；应先诊断。

### 误区 2：能复制文字就说明解析合格

不对。仍可能乱码、错序、重复或表格关系丢失。

### 误区 3：OCR 输出就是原文

不对。OCR 是识别结果，关键字段必须保留原页、置信度和风险校验。

### 误区 4：版面识别只是视觉美化

不对。它决定阅读顺序、标题归属、表格关系和脚注关联，直接影响 RAG 事实正确性。

## 本节练习

### 练习 1：文本提取、OCR、版面识别分别解决什么问题？

答案：文本提取读取 PDF 文字层中的字符；OCR 从图片中识别文字；版面识别恢复标题、段落、表格、页眉脚等空间结构与阅读顺序。

### 练习 2：一份 PDF 能复制文字，但双栏内容左右交替。应优先怎样处理？

答案：它不一定需要全量 OCR，主要需要版面分析和阅读顺序恢复；之后还要抽样确认标题、正文和页码关联正确。

### 练习 3：为什么扫描合同中的日期不应只依赖 OCR 结果？

答案：数字和字符容易混淆，印章或低清晰度还可能遮挡内容。日期属于高风险字段，应保留原页并结合格式、上下文或人工审核核验。

## 自测题

### 自测 1：什么是混合 PDF？

答案：同一文件同时包含可直接提取的文字层和图片化、扫描化内容，例如正文可复制但附件或截图需 OCR。

### 自测 2：文件诊断的核心原则是什么？

答案：先判断每份文件、页面或区域的真实特征，再选择文本提取、OCR、版面分析或人工复核的组合路径。

### 自测 3：本节最重要的结论是什么？

答案：PDF 视觉正常不等于机器可读正确。解析前必须诊断，解析后必须验证，不能把任何自动提取结果直接当作可信知识。
